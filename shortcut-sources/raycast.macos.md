# Raycast keyboard shortcuts (macOS)

Source: https://manual.raycast.com/keyboard-shortcuts

## Global Shortcuts

| Action | Shortcut | Comment |
| --- | --- | --- |
| Open or close Raycast | cmd+space | Default, can be customized |

## General Navigation

| Action | Shortcut | Comment |
| --- | --- | --- |

| Pop to Root | cmd+esc |  |
| Close the Raycast window | cmd+w |  |
| Open Settings | cmd+, |  |
| Open the User Guide | shift+cmd+/ |  |
