# Raycast keyboard shortcuts (Windows)

Source: https://manual.raycast.com/keyboard-shortcuts

## Global Shortcuts

| Action | Shortcut | Comment |
| --- | --- | --- |
| Open or close Raycast | alt+space | Default, can be customized |

## General Navigation

| Action | Shortcut | Comment |
| --- | --- | --- |
| Go back | esc | From Root Search, closes Raycast window |
| Pop to Root | shift+esc |  |
| Close the Raycast window | ctrl+w |  |
| Open Settings | ctrl+, |  |
| Open the User Guide | ctrl+shift+/ |  |
